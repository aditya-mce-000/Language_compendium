C PROGRAMMING — LEVEL-UP PROBLEM SET
=========================================
Based on: The Ultimate C Handbook

IMPORTANT
---------
This is a fully specified problem set. Each question includes the actual
expressions, values, input format, examples, or exact requirements needed
to solve it.

Do NOT look for the solution in the question. The goal is for you to write
the C programs yourself.

============================================================
LEVEL 1 — CORE CONCEPTS + OPERATORS
============================================================

1. EXPRESSION DETECTIVE
-----------------------
Predict the output of EACH program before running it.

A)
    int a = 10, b = 3;
    printf("%d\n", a + b * 2);

B)
    int a = 10, b = 3;
    printf("%d\n", (a + b) * 2);

C)
    int a = 10, b = 3;
    printf("%d\n", a / b);

D)
    int a = 10;
    float b = 3;
    printf("%.2f\n", a / b);

E)
    int a = 5, b = 2;
    printf("%d\n", a > 3 && b < 5);

F)
    int a = 5, b = 10;
    printf("%d\n", a == 5 || b == 5);

G)
    int x = 5;
    printf("%d\n", x++ + ++x);

For every expression, explain:
- operator precedence
- associativity where relevant
- integer division
- type conversion
- whether the expression is well-defined C

2. TYPE CONVERSION CHALLENGE
----------------------------
Write a program that asks for two integers a and b.

Example input:
    10 3

Print:
    Integer division: 3
    Floating division: 3.333333
    Explicit cast result: 3.333333

Then repeat the calculation using:
    float x = a;
    float y = b;

Explain why the results differ.

3. NUMBER CLASSIFIER
--------------------
Input one integer N.

Example:
    Input: -30

Output:
    Sign: Negative
    Even/Odd: Even
    Divisible by 3: Yes
    Divisible by 5: Yes

Test at least:
    0
    7
    -15
    24

4. PRECEDENCE PUZZLE
--------------------
Predict the output of these:

A)
    int x = 5 + 3 * 2;

B)
    int x = (5 + 3) * 2;

C)
    int x = 20 / 5 * 2;

D)
    int x = 10 > 5 && 3 < 2;

E)
    int x = 10 > 5 || 3 < 2;

F)
    int x = 5 + 2 > 6;

G)
    int x = 5 * 2 == 10;

Write a program that prints all seven results.

5. NUMBER STATISTICS
--------------------
Input a positive integer.

Example:
    Input: 58321

Output:
    Digits: 5
    Sum: 19
    Product: 240
    Largest digit: 8
    Smallest digit: 1
    Even digits: 2
    Odd digits: 3

Do not convert the number into a string.

6. SECOND LARGEST DIGIT
-----------------------
Input a positive integer.

Example:
    Input: 58321
    Output: Second largest digit = 5

Example:
    Input: 9988
    Output: Second largest distinct digit = 8

If there is no second-largest distinct digit, print:
    No second-largest distinct digit

7. NUMBER PROPERTY ANALYZER
---------------------------
Input an integer N and check:

- Is it a palindrome?
- Is it prime?
- Is it a perfect square?
- Is it an Armstrong number?
- Is it divisible by the sum of its digits?

Example:
    Input: 121

Possible output:
    Palindrome: Yes
    Prime: No
    Perfect square: Yes
    Armstrong: No
    Divisible by digit sum: Yes

8. DIGITAL ROOT — LOOP + RECURSION
----------------------------------
Input:
    9875

First calculate the digital root using loops.

Example:
    9 + 8 + 7 + 5 = 29
    2 + 9 = 11
    1 + 1 = 2

Output:
    Digital root using loop: 2
    Digital root using recursion: 2

Write two separate functions:
    int digitalRootLoop(int n)
    int digitalRootRecursive(int n)

9. PRIME PAIR SEARCH
--------------------
Input an even integer N.

Find all pairs of prime numbers p and q such that:
    p + q = N

Example:
    Input: 10

Output:
    3 + 7 = 10
    5 + 5 = 10

Do not print duplicate reversed pairs such as:
    7 + 3 = 10

10. MULTIPLICATION TABLE MATRIX
------------------------------
Input N.

For N = 5, print multiplication tables from 1 to 5 in aligned columns.

Example format:

    1x1=1    2x1=2    3x1=3    4x1=4    5x1=5
    1x2=2    2x2=4    3x2=6    4x2=8    5x2=10
    ...
    1x10=10  2x10=20  3x10=30  4x10=40  5x10=50

Use nested loops.

---------------------

Example:
    Input: 12345
    Output: 54321

Do not convert the number to a string.

----------------------

Pattern 1, N = 5:
    *
    **
    ***
    ****
    *****

    *****
    ****
    ***
    **
    *

-----------------

    int gcd(int a, int b)

17. POINTER INSPECTOR
---------------------
Create:

    int x = 10;
    float y = 5.5;
    char c = 'A';

Create pointers to each variable.

Print:
- value of each variable
- address of each variable
- value obtained by dereferencing its pointer

Then modify all three variables using their pointers.

18. SWAP + ROTATE
-----------------
Create:

    void swap(int *a, int *b)

Then create:

    void rotate(int *a, int *b, int *c)

For:
    a = 10
    b = 20
    c = 30

After rotation:
    a = 30
    b = 10
    c = 20

Use pointers. Do not return a structure or array.

19. MULTIPLE OUTPUTS THROUGH POINTERS
-------------------------------------
Create:

    void analyze(int n, int *square, int *cube, float *half, int *doubleValue)

Example:
    Input: 5

Output:
    Square: 25
    Cube: 125
    Half: 2.50
    Double: 10

All four results must be produced through pointer parameters.

20. POINTER-BASED NUMBER ANALYZER
---------------------------------
Write:

    void analyzeNumber(int n, int *digits, int *sum,
                       int *largest, int *smallest)

For:
    Input: 58321

Output:
    Digits: 5
    Sum: 19
    Largest: 8
    Smallest: 1

The function must modify the results through pointers.

21. POINTER-TO-POINTER CHALLENGE
--------------------------------
Create:

    int x = 10;
    int *p = &x;
    int **pp = &p;

Perform these operations:

1. Print x.
2. Print *p.
3. Print **pp.
4. Change x to 50 using *p.
5. Change x to 100 using **pp.

Then explain the difference between:
    x
    *p
    **pp
